The browser rows run the ticket's own browser test once in the temporary worktree and each reads its tests by title from the one report: the last three numbers of such a line are tests passed, failed and skipped, and a test marked `fixme` is counted as skipped, which is not a pass. A row that changes a file of the temporary worktree restores it and is paired with the unchanged run (the paired part is named in Expected). A row that cannot be shown prints `Blocked` and the reason; the manual rows print `Blocked` until the QA pastes a result. The rows whose Expected is what the spec requires and which the Version may not meet (the fonts section, the fonts link, `check:fonts`, the `.woff2` requests, the screenshot test, `lint:boundaries`) are judged as written (concern 4 of the spec of this record).
