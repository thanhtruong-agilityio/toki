# QA record: TOKI-018
Ticket: TOKI-018
Spec: docs/specs/2026-11-16-platform-package-design.md
Version: f9aa289
Environment: a temporary worktree of the Version under Node 22 (`~/.nvm`), pnpm through corepack, macOS; the Playwright of the Version with the Chromium it has cached (new headless mode, a profile folder for each context), the Vite dev server of `apps/web` in the worktree on a free loopback port; a temporary PostgreSQL 14.24 (Homebrew) cluster made with `initdb` on a loopback port for `pnpm test` (not the PostgreSQL 17 of Compose; the Docker services and the real development database are not touched); Safari and Firefox are not run by command; the repository itself is not changed

Role: Dev is Thanh Truong with Claude (the ticket was built before this record). QA is Thanh Truong. Claude drafts the rows; the QA approves them before any row is run. Claude runs the command rows; the QA runs the manual row.

Each row runs `V=f9aa289 bash docs/qa/TOKI-018.checks.sh <ID>` (called `checks` below) and compares its one output line with Expected. The output goes in `docs/qa/TOKI-018.evidence.txt`. `f9aa289` is the merge commit of PR #144 (2026-11-18), decided in concern 1 of the spec of this record; `Expected` is the text of the spec of TOKI-018 as it stood at that commit (concern 3), and a requirement of the revised spec that the code at `f9aa289` does not meet is a Fail with a note. The rows that change a file of the temporary worktree restore it and are paired with a run that must pass; the rows of R5 print a control from the same page next to each zero. The browser rows drive Chromium with Playwright against the dev app of the worktree: the page is a made-up one served at the origin of the dev server, which loads the web implementation of the package; a call "with no press" is a page script at load, because Playwright's own calls count as a press. The manual row is `Blocked` until the QA pastes the result. No `.env` is read or created; no tool output is kept.
