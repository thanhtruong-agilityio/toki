Role: Dev is Thanh Truong with Claude (the ticket was built before this record). QA is Thanh Truong. BA is Thanh Truong. Claude drafts the rows; the QA approves them before any row is run. Claude runs the command rows; the QA runs the four manual rows and pastes the result.

Each command row runs `V=80b962b bash docs/qa/TOKI-012.checks.sh <ID>` (called `checks` below) and compares its one output line with Expected. The output goes in `docs/qa/TOKI-012.evidence.txt`. `80b962b` is the merge commit of PR #136 (2026-11-18), decided in concern 1 of the spec of this record. The rows that change a file of the temporary worktree restore it and are paired with an unchanged run (T53, T64, T71, T77); T28 and T29 are paired with the same controls at 720 px. The CSS rows read the tables of the spec of TOKI-012 at the Version and compare them with the CSS files, so they do not rely on the CSS tests of the ticket. No `.env` is read or created; no secret and no tool output is kept. Rows T54 to T57, T69 and T71 name things that the spec of TOKI-012 states and that the Version may not have (`tools/eslint-rules`, `tools/lint-fixtures`, `pnpm lint:boundaries`, the fonts import); Expected is what the spec states, and the result notes say what the Version has.
