# QA record: TOKI-010
Ticket: TOKI-010
Spec: docs/specs/2026-11-16-self-hosted-fonts-design.md
Version: 5a8e7df
Environment: a temporary worktree of the Version under Node 22 (`~/.nvm`), pnpm through corepack with its own `pnpm install --frozen-lockfile`, macOS; the font files are read with fontkit 2.0.4, the version the Version pins in `apps/web`; the production build of the web app (`pnpm --filter ./apps/web build`) and `vite preview` on a free loopback port; the headless Chromium cached by Playwright (the `@playwright/test` of the worktree), driven over the Chrome DevTools Protocol; Safari is not available to the script (rows T13D and T13E are by eye); nothing is written to GitHub and the repository itself is not changed

Role: Dev is Thanh Truong with Claude (the ticket was built before this record). QA is Thanh Truong. Claude drafts the rows; the QA approves them before any row is run. Claude runs the command and e2e rows; the manual rows wait for the QA.

Each command and e2e row runs `V=5a8e7df bash docs/qa/TOKI-010.checks.sh <ID>` (called `checks` below) and compares its one output line with Expected; a line that starts with two spaces under it is a detail (where the delivered files are). The output goes in `docs/qa/TOKI-010.evidence.txt`. `5a8e7df` is the merge commit of PR #171 (2026-11-19), decided in concern 1 of the spec of this record; every row is judged at it, and the evidence line of each row names it. The rows are judged against the spec of TOKI-010 as written (concern 4): the spec puts the fonts, `fonts.css`, `sources.json` and `licenses/` in `apps/web/src/fonts/`, so the rows of R1, R2, R7, R14 and R15 read that folder and are expected to fail where the delivered files are elsewhere; the detail line shows the delivered path and the same measure there. The rows that change a file of the temporary worktree restore it with `git checkout` and are paired with an unchanged run; the other rows carry a control that must be flagged (the last number of the line). A row that cannot be run is `Blocked`, never `Pass`. No `.env` is read or created; no secret and no tool output is kept.
