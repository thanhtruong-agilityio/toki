T12 and T19 need the QA's approval again and a rerun; the rows are rerun twice and both runs are kept in the evidence file.
- **How the history rows were read.** They read the runs of `ci.yml` created from the first commit of PR #107 up to 2026-11-25T03:54:59Z, with read-only `gh api` requests (the `HISTORY` line of the evidence gives the numbers of runs and jobs); nothing was written to GitHub and no pull request was opened. The history shows how CI behaved from the delivering pull request onward; the workflow changed after the delivery (see the last section of the evidence file), so a history row is not a reading of the file at the Version, and for T12 the Node and pnpm lines come from a later run of the later workflow.
- **Discarded runs.** The first attempt at the official run gave different numbers on two passes (for example 49 and 36 failed runs with a failed job) because the unauthenticated API rate limit had been used up by the debugging runs and GitHub refused some requests that the script then skipped; those two passes are not evidence and their lines are listed in the evidence file under their own heading. The script was then changed to retry, to drop malformed answers, to fix the snapshot, to cache the answers and to report the history as unreadable (Blocked) instead of counting a partial one.
