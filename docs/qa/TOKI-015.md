Environment: a temporary worktree of the Version under Node 22 (`~/.nvm`), pnpm through corepack with `pnpm install --frozen-lockfile` run in it, macOS; the unit tests of `ui-web` and Vitest with jsdom, the TypeScript compiler, ESLint, Prettier, the Vite build of `apps/web` and the bundle size check of the repository; the Vite dev server of the worktree on a free loopback port and the headless Chromium cached by Playwright, driven by `@playwright/test`, against the fixture page `shell-fixture.html` of the ticket; the ticket's own browser test `e2e/app-shell.spec.ts` and `pnpm test:e2e` on the ports 5173 and 3000 that the Playwright config fixes (a row is Blocked when one is taken); the probes, the type files and the driver exist only in the temporary worktree; the manual rows use the fixture that `checks serve` starts, the prototype and a screen reader; no `.env` is read or created and the repository itself is not changed

Role: Dev is Thanh Truong with Claude (the ticket was built before this record). QA is Thanh Truong. Claude drafts the rows; the QA approves them before any row is run. Claude runs the command rows; the QA runs the manual rows and pastes the result.

Each command row runs `V=2c3330ef bash docs/qa/TOKI-015.checks.sh <ID>` (called `checks` below) and compares its one output line with Expected. The output goes in `docs/qa/TOKI-015.evidence.txt`. `2c3330ef` is the merge commit of PR #157, decided in concern 1 of the spec of this record. A row that relies on tests of the ticket names the test file and the test, and its line says how many passed and failed; a row that changes a file of the temporary worktree restores it and is paired with the unchanged run (the word `mutated` in a line marks the values of the changed copy), and a row that only reads files is paired with a changed copy of the text held in memory. A requirement that names a path that the delivery moved (`src/shell`, tests beside the sources, `src/shell-fixture`) is a Fail by concern 5: its row prints the files found at the spec's path and at the path found at the Version, and still compares the behavior where the code is. A row that cannot be shown prints `Blocked` and the reason. The manual rows print `Blocked` until the QA pastes a result. No `.env` is read or created; no tool output and no secret is kept.
